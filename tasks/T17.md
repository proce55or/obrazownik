# T17: Lokalny Bielik i buforowane pytania

Wyraźnie zlecone przez użytkownika 2026-11-03 jako dodatkowy etap po MVP.
Zgoda obejmuje pobranie Bielika7B, lokalny runtime, testy i opcjonalną
integrację. Nie obejmuje płatnej chmury ani wysyłania tekstów poza komputer.

1. Runtime CPU dopasowany do Intel/Ventura, wagi GGUF poza repo, SHA256.
2. Pomiar rzeczywistego czasu i jakości krótkich polskich podpowiedzi.
3. Domyślny tryb bez LLM; osobny lokalny Bielik. Próby niezależne bez LLM.
4. Buforowanie neutralnego pytania po otwarciu zadania, bez wyświetlania.
   Pokazanie wyłącznie na żądanie, ze snapshotem i oznaczeniem źródła.
5. Zapis modelu/hash/promptVersion oraz trybu próby, eksport/import tych danych.
6. Timeout i niedostępny model nie blokują zapisu ani gotowych podpowiedzi.
7. Testy cache, nieujawnionej pomocy, idempotencji, niezależności i danych;
   rzeczywisty odbiór UI obu trybów. Dane testowe wyłącznie tmpdir.
8. Instrukcja krok po kroku: kto/co/katalog, start/stop, porównanie jutro.
9. Sprawdzony commit i push do prywatnego remote. Limit użytkownika:
   zatrzymać z zapasem przed80% zużycia, zostawić20% konta.

Bez generowania odpowiedzi autora, treningu/LoRA i automatycznej oceny wiersza.
