# T01: Lokalny szkielet
## Czytaj
docs/03-architecture.md A3–A5; docs/01-product.md P2–P3.

## Cel
Uruchomić jeden działający ekran i lokalny serwer, bez atrap zdalnych usług.

## Wykonanie
1. Jeden pakiet npm: TypeScript strict, React/Vite, Fastify, schematy.
Przypnij lockfile. Nie używaj generatora nadpisującego pliki planu.
2. Utwórz granice src/client, server, domain, shared. Nie wypełniaj ich
pustymi dziesiątkami modułów na przyszłość.
3. Frontend Dzisiaj z jedną drogą do ćwiczenia. API /health i /bootstrap.
4. Produkcyjny serwer serwuje build i API na 127.0.0.1:4317.
Dev Vite ma proxy. Zweryfikuj Host/Origin i zaplanuj CSRF dla zmian.
5. Skrypty dev/build/start/check; check nie może zgłaszać nieistniejących testów
jako zaliczonych. Test health i nasłuchu. Lokalny CSS/font bez CDN.
6. Rozwiązywanie folderu danych poza repo i test błędnej konfiguracji.
Na razie bez bazy osobistych tekstów.

## Odbiór
- Build startuje i ekran otwiera się z lokalnego adresu.
- /health zwraca wersję; brak nasłuchu 0.0.0.0.
- Nie ma żądań do CDN ani kluczy w bundle.
- Ścieżka danych jest niezależna od cwd, niedozwolone zagnieżdżenie odrzucone.

## Poza tym zadaniem
Bez service workera, kont, cloud deployment i drugiej bazy na telefonie.

## Zamknięcie
Uaktualnij STATE.md i status w tasks/INDEX.md. Zapisz rzeczywiste komendy
i wyniki. Uruchom node scripts/check-context.mjs. Sprawdź diff przed commitem.
Jeśli kryterium wymaga niedostępnego iMaca, zapisz VERIFY_ON_MAC, nie fikcyjny sukces.
