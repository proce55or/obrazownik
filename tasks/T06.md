# T06: Prywatny zeszyt
## Czytaj
docs/01-product.md P3–P4; docs/02-exercises.md E5; docs/04-data-api.md D2–D4.

## Cel
Pozwalać pracować z własnym materiałem i porównywać wersje bez niszczenia oryginału.

## Wykonanie
1. Zeszyt: lista, wyszukiwanie, filtry rodzin/pomocy, podgląd wersji.
Paginacja, nie ładowanie całej bazy do React state.
2. Tworzenie dokumentu przez wpisanie/wklejenie lub świadomy import .txt/.md.
Bez automatycznego skanowania folderów. Wczytuj jako tekst.
3. E5 może użyć wybranego dokumentu. Nowy fragment zapisz jako pochodny tekst
z powiązaniem; oryginał pozostaje.
4. Zachowanie ręcznych wersji, proste porównanie dwóch tekstów.
Możliwość ukrycia dat i losowej kolejności tylko w porównaniu, bez zmiany danych.
5. Eksport pojedynczego tekstu Markdown i całości JSON (pełny import T07).
6. Sprawdź konflikt dwóch kart, polskie znaki, HTML w tekście i niezmienny oryginał.

## Odbiór
- Praca na własnym tekście nie zastępuje oryginału.
- Syntetyczny dokument z nawiasami i tagami nie wykonuje HTML/JS.
- Porównanie nie nadaje tekstom punktów ani automatycznej diagnozy.
- Eksport jest czytelny i zawiera oznaczenie użytej pomocy przy próbach.

## Poza tym zadaniem
Bez konieczności dostarczenia wierszy użytkownika i bez profilowania dawnego stylu.

## Zamknięcie
Uaktualnij STATE.md i status w tasks/INDEX.md. Zapisz rzeczywiste komendy
i wyniki. Uruchom node scripts/check-context.mjs. Sprawdź diff przed commitem.
Jeśli kryterium wymaga niedostępnego iMaca, zapisz VERIFY_ON_MAC, nie fikcyjny sukces.
