# Aktualne decyzje

Data bazowa: 2026-11-02.

  w folderze na Macu. Zastępuje wcześniejsze MVP oparte wyłącznie na IndexedDB.

- D08: Autorstwo i licencja treści do ustalenia przed publicznym wydaniem;
