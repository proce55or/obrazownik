# Obrazownik: dodatek naukowy do istniejącej aplikacji

Wersja 1.0, 2 listopada 2026. Język aplikacji: wyłącznie polski.

Cel: wspomóc samodzielne znajdowanie słów, budowanie obrazów i pisanie we własnym głosie. Dodatek rozwija istniejący plan; nie zastępuje go i nie nakazuje przebudowy aplikacji.

## Jak korzystać

1. Użytkownik: przeczytaj `docs/science/01-evidence.md`.
2. Model na Macu: rozpocznij od `PROMPT_MODYFIKACJI.md`, następnie wykonaj inwentaryzację aktualnego repozytorium.
3. Wdrażaj po jednym etapie SCI z `docs/science/03-integration.md`. Czytaj wyłącznie potrzebny fragment metod.
4. Bibliografię otwieraj według identyfikatora R01–R22, nie w całości przy każdej sesji.

| Plik | Zawartość |
|---|---|
| 01-evidence.md | Co wynika z badań, czego nie wykazano, priorytety zmian |
| 02-methods.md | Polskie warianty ćwiczeń i autorskie przykłady |
| 03-integration.md | Wdrożenie, pomiar transferu, dane, testy i pamięć projektu |
| 04-sources.md | Metody i interwencje, typ badania, ograniczenia i URL |
| 05-sources-pl.md | Polskie badania i zasoby; razem z 04: 22 publikacje |
| PROMPT_MODYFIKACJI.md | Instrukcja wykonawcza dla modelu pracującego nad aplikacją |

Pełny appendix w jednym pliku jest wersją do czytania poza repozytorium. Do repo dodaj moduły, bez drugiej kopii całego raportu.

Nie nadpisuj istniejących AGENTS.md, STATE.md, PROJECT.md ani numeracji zadań. Jeżeli repo ma już własne zasady, połącz wymagania dodatku z aktualnym stanem. Pakiet nie zawiera kodu aplikacji, danych użytkownika ani cudzych PDF-ów.
